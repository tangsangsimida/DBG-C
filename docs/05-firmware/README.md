DBG-C-FW-001 V0.77 记录了 PB8 KEY_MODE/PB9 LED_TARGET 原始 GPIO 适配器及 56 项主机检查（不定义电气策略），以及 PB6 TARGET_PWR_EN 原始 GPIO 适配器及 36 项主机检查（未定义供电极性），以及 SPI1 配置 BSP 19 项及 PA0–PA3 GPIO 模式及 PA3 原始片选电平 BSP 104 项主机模拟寄存器检查及 ThreadX CH585M 实验性 low-level 与 SysTick 接入、WCH EVT 来源、MounRiver GCC 12 环境配置、固定路径两次 clean rebuild 的 ELF/map 一致性，以及启动、上下文和中断路径静态审查。CH585 BSP/适配器已纳入 PoC CMake 构建图中的 `dbgc_ch585_platform` 静态库目标，但 PoC 应用未调用这些接口。Target JTAG GPIO BSP 已按 PB0–PB3 编址并通过 116 项模拟寄存器主机检查；另有独立主机模型将固定上游 CMSIS-DAP JTAG Sequence、IDCODE 和 DP Transfer 写入/posted-read 命令路径经 BSP 执行，累计 1610 项检查。产品固件尚未集成该路径，实体目标及板级行为未验证。主机验证覆盖定长包队列（54 项检查）、镜像更新事务管理器（57 项检查）、FIFO、CMSIS-DAP 命令核心与边界预检/有界 dispatch、经 CH585 GPIO BSP 和模拟寄存器执行的 SWD 引擎线模型（10 个用例、3321 项断言，含命令层 DP 写入）、通用 Target Reset 序列服务、GPIO/UART/UID 适配器和 PA4/A0 原始 ADC 采样适配器（44 项主机模拟寄存器检查）等，详见主文档和 TEST-001。1000 tick/s 基线已完成固定路径两次一致的干净构建，验证板软件放行门已通过，只允许设计带编程/恢复及复位、系统时钟、SysTick、中断活动观测/测量点的限定用途验证板；这不代表芯片运行通过，也不允许冻结产品原理图或 PCB。PoC-1 ThreadX 启动、中断、tick、线程切换/睡眠/唤醒和持续运行仍未做实板验证，相关用例保持未执行；产品硬件冻结未放行。

DBG-C-FW-001 V0.77 records the PB8 KEY_MODE/PB9 LED_TARGET raw GPIO adapter and 56 host checks without electrical policy, plus the PB6 TARGET_PWR_EN raw GPIO adapter and 36 host checks without a power polarity definition, plus SPI1 configuration BSP with 19 modeled-register host checks and PA0–PA3 GPIO mode and raw PA3 chip-select BSP with 104 modeled-register host checks and the experimental ThreadX CH585M low-level and SysTick integration, WCH EVT provenance, MounRiver GCC 12 setup, matching ELF/map hashes from two clean rebuilds at a fixed path, and static review of startup, context, and interrupt paths. The CH585 BSP/adapters are included in the PoC CMake graph as the `dbgc_ch585_platform` static-library target, but the PoC application does not call them. The Target JTAG GPIO BSP maps PB0–PB3 and passes 116 modeled-register host checks; a separate host model connects the pinned CMSIS-DAP JTAG Sequence, IDCODE, and DP Transfer write/posted-read paths through this BSP for 1610 cumulative checks. These test paths are not integrated into product firmware or validated against a physical target. Host checks cover the generic fixed-slot packet queue (54 checks), update transaction manager (57 checks), FIFO, CMSIS-DAP command core and bounds-preflight/bounded dispatch, ten SWD-engine line-model cases through CH585 GPIO BSP and modeled registers (3321 assertions, including command-level DP write), generic Target Reset sequencing (24 callback checks) and PB5 reset-sequence adapter integration (37 modeled-register checks), GPIO/UART/UID adapters and the PA4/A0 raw ADC adapter (44 modeled-register host checks), and related modules; see the main document and TEST-001 for exact evidence. The software release gate has passed for limited-purpose verification-board design only. That board must provide programming/recovery and observation/measurement access for reset, system clock, SysTick, and interrupt activity. This does not establish chip runtime success or release product schematic/PCB freeze. PoC-1 ThreadX startup, interrupts, tick, thread switching/sleep/wakeup, and sustained operation remain unverified on hardware, with related cases Not run; product-hardware freeze is not released.
