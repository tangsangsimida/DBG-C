本目录预留给 DBG-C-FW-001《Firmware Architecture》及后续实现计划。V1 已确定引用 [Eclipse ThreadX 官方 GitHub 项目](https://github.com/eclipse-threadx/threadx)。集成时须锁定正式发布标签或提交哈希；ThreadX 版本、工具链和 CH585M 移植方式须先核验，并记录上游许可证声明。按阶段计划，先完成需求、接口、系统架构和 MCU 资源核验，再建立固件架构文档；当前尚无固件源码或 SDK 供核对。

This directory is reserved for DBG-C-FW-001, *Firmware Architecture*, and the implementation plan. V1 will reference the [official Eclipse ThreadX GitHub project](https://github.com/eclipse-threadx/threadx). Integration must pin a formal release tag or commit hash; the ThreadX version, toolchain, and CH585M port require verification, and upstream license notices must be recorded. Per the project phases, firmware architecture follows requirements, interface/system architecture, and MCU resource verification. No firmware source or SDK is currently available for review.
