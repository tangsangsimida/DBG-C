# 固件文档 | Firmware Documents

本目录预留给 DBG-C-FW-001《Firmware Architecture》及后续实现计划。V1 已确定通过 Git Submodule 引用 [Eclipse ThreadX 官方 GitHub 项目](https://github.com/eclipse-threadx/threadx)，由主仓库记录其 URL 和精确 commit。子模块路径将在固件仓库布局冻结时登记；正式发布标签、工具链和 CH585M 移植方式须先核验，并记录上游许可证声明。按阶段计划，先完成需求、接口、系统架构和 MCU 资源核验，再建立固件架构文档；当前尚无固件源码或 SDK 供核对。

This directory is reserved for DBG-C-FW-001, *Firmware Architecture*, and the implementation plan. V1 will reference the [official Eclipse ThreadX GitHub project](https://github.com/eclipse-threadx/threadx) through a Git Submodule, with its URL and exact commit recorded by the superproject. The submodule path will be recorded when the firmware repository layout is frozen. Verify the formal release tag, toolchain, and CH585M port, and retain upstream license notices. Per the project phases, firmware architecture follows requirements, interface/system architecture, and MCU resource verification. No firmware source or SDK is currently available for review.
