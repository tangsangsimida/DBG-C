DBG-C-FW-001 V0.30 记录了 ThreadX CH585M 实验性 low-level 与 SysTick 接入、WCH EVT 来源、MounRiver GCC 12 环境配置、可复现主机 ELF 构建与静态审查；通用 FIFO 主机 3683 项断言、CMSIS-DAP 命令核心 8 项、SWD 引擎线模型 9 项检查通过，并新增基于 WCH EVT GPIOB 模式配置语义与 MCU-001 PB5/PB6 分配的 SWD GPIO BSP。SWD GPIO BSP 通过 57 项、PA4 Target Reset GPIO BSP 通过 33 项模拟寄存器主机检查，且两者均通过 ELF32 RISC-V 目标对象编译，未链接 PoC 或 CMSIS-DAP，也未实板运行；电气模式、SWD 时序、USB/UART 集成仍未验证。主机寄存器模型不证明芯片寄存器行为、PA4 电气输出或目标复位效果；软件门只放行限定用途的验证板设计。PoC-1 ThreadX 运行验证未执行，产品硬件冻结未放行。CMSIS-DAP O21 仍待确定产品命令配置、厂商命令策略、字符串回调写入上限、USB 收包长度和缓冲容量。

DBG-C-FW-001 V0.30 records the experimental ThreadX CH585M low-level and SysTick integration, WCH EVT provenance, MounRiver GCC 12 setup, reproducible host ELF builds, and static review. The generic FIFO has 3683 passing host assertions; eight CMSIS-DAP command-core cases and nine SWD-engine line-model cases pass. The CH585 SWD GPIO BSP passes 57 modeled-register host checks, and the PA4 Target Reset GPIO BSP passes 33; both compile to ELF32 RISC-V objects. Neither is linked into PoC or CMSIS-DAP or run on hardware. Electrical modes, reset pulse behavior, SWD timing, and USB/UART integration remain unverified. Register models do not prove silicon behavior or target reset effect. The software gate only releases limited-purpose verification-board design. PoC-1 ThreadX runtime verification is Not run; product-hardware freeze is not released. CMSIS-DAP O21 remains open pending the product command profile, vendor-command policy, string-callback write bounds, USB receive length, and buffer capacities.
