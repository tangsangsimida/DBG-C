DBG-C-FW-001 V0.32 记录了 ThreadX CH585M 实验性 low-level 与 SysTick 接入、WCH EVT 来源、MounRiver GCC 12 环境配置、可复现主机 ELF 构建与静态审查；通用 FIFO 主机 3683 项断言、CMSIS-DAP 命令核心 8 项、SWD 引擎线模型 9 项及 CMSIS-DAP 边界预检 102 项检查及有界 dispatch 3 个主机用例通过。SWD GPIO BSP 通过 57 项、PA4 Target Reset GPIO BSP 通过 33 项模拟寄存器主机检查，且 GPIO BSP 与边界预检/dispatch 模块通过 ELF32 RISC-V 目标对象编译；dispatch 尚未接入产品 USB 收包路径，也未在实板运行。边界预检使用显式测试 profile，vendor/SWO/CMSIS-DAP UART 路径失败关闭；产品命令配置、Info 回调上限、USB 收包长度及缓冲容量仍待确认，O21 保持开放。GPIO 电气模式、SWD 时序、USB/UART 集成仍未验证。软件门只放行限定用途的验证板设计；PoC-1 ThreadX 实板运行验证未执行，产品硬件冻结未放行。

DBG-C-FW-001 V0.32 records the experimental ThreadX CH585M low-level and SysTick integration, WCH EVT provenance, MounRiver GCC 12 setup, reproducible host ELF builds, and static review. The generic FIFO has 3683 passing host assertions; eight CMSIS-DAP command-core cases, nine SWD-engine line-model cases, 102 CMSIS-DAP bounds-preflight checks and three bounded-dispatch host cases pass. The SWD GPIO BSP passes 57 modeled-register host checks, and the PA4 Target Reset GPIO BSP passes 33; the GPIO BSPs and bounds preflight/dispatch module compile to ELF32 RISC-V objects. The dispatcher is not connected to product USB receive and has not run on hardware. The bounds preflight uses an explicit test profile and fails closed for vendor/SWO/CMSIS-DAP UART commands; product command settings, Info callback bounds, USB receive length, and buffer capacities remain undefined, so O21 stays open. GPIO electrical modes, reset pulse behavior, SWD timing, and USB/UART integration remain unverified. The software gate only releases limited-purpose verification-board design. PoC-1 ThreadX runtime verification is Not run; product-hardware freeze is not released.
